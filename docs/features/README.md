# DeepReader 功能特征

> 每个功能含：**为什么存在 / 用户故事 / 前置条件 / 输入 / 输出 / 验收标准 / 测试覆盖**。
> 内核原因（"为什么存在"）是功能存在的根本理由，所有设计和取舍以此为判断标准。
