# AI 回复质量优化方案

**创建时间**: 2026-07-03
**目标**: 优化超时问题，提升关键词命中率

## 1. 超时问题优化

### 1.1 LLM 调用超时配置 ✅

**已实施**:
- `ModelConfig` 接口添加 `requestTimeout` 字段
- `mainModel` 默认 60 秒超时
- `fastModel` 默认 30 秒超时

**效果**: 防止 LLM 调用无限等待，避免用户长时间无响应

### 1.2 响应缓存（建议实施）

**方案**:
- 对相同查询实现内存缓存
- 缓存 TTL: 5 分钟
- 缓存键: 查询 + 书籍 ID

**预期效果**: 减少重复 LLM 调用，降低超时风险

### 1.3 流式响应优化（建议实施）

**方案**:
- 优化 chunk 处理逻辑
- 减少前端渲染延迟
- 实现渐进式内容展示

**预期效果**: 提升首字节时间，改善用户体验

## 2. 关键词命中率提升

### 2.1 Prompt 优化（建议实施）

**当前问题**:
- 部分回答遗漏关键词
- 关键词匹配不完整

**优化方案**:
1. **强化关键词输出要求**
   ```
   <rules>
   7. 【关键词输出】：回复中必须包含以下核心概念词：{keywords}。
      自然融入句子，不要刻意堆砌。
   </rules>
   ```

2. **添加示例**
   ```
   <examples>
   用户问："AI如何降低决策成本？"
   必须包含：决策、成本、预测、判断
   
   正确示例：
   "AI通过降低预测成本，改变了决策方式。当预测变得廉价，企业不再依赖直觉判断，
   而是利用数据驱动决策，从而降低了整体决策成本。"
   
   错误示例：
   "AI让企业更聪明地做决定。"（遗漏关键词）
   </examples>
   ```

### 2.2 检索优化（建议实施）

**方案**:
- 优化 BM25 检索算法
- 调整向量搜索权重
- 实现混合检索策略

**预期效果**: 提高检索结果相关性，确保关键词覆盖

### 2.3 回复验证（建议实施）

**方案**:
- 在 formatter 节点添加关键词验证
- 检查回复是否包含预期关键词
- 如遗漏，追加补充说明

**预期效果**: 确保关键词完整输出

## 6. 风险评估

### 低风险
- LLM 超时配置：仅添加超时限制，不影响现有逻辑
- Prompt 优化：仅修改指令，不影响代码结构

### 中风险
- 响应缓存：需要处理缓存失效和一致性
- 流式响应：需要修改前端渲染逻辑

### 高风险
- 检索算法优化：可能影响搜索结果质量
- 回复验证：可能增加 LLM 调用次数
