# 新书引导按钮设计

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为首次切换到新书的用户提供引导按钮，帮助用户快速开始与 AI 对话

**Architecture:** 在现有空状态 UI 基础上，将单个"生成阅读大纲"按钮扩展为 6 个引导按钮，其中 5 个为快捷问题，1 个为 AI 主动引导入口

**Tech Stack:** TypeScript, Obsidian Plugin API

---

## 需求背景

当前切换到新书时，只有一个"生成阅读大纲"按钮，功能单一。需要结合分层阅读方法论，提供更多提问入口，改善新用户的首次体验。

## 功能设计

### 引导按钮列表

| 按钮 | 行为 | 提示词 |
|------|------|--------|
| 这本书讲了什么 | 发送问题，AI 回复概览 | "这本书主要讲了什么内容？请给我一个概览" |
| 核心观点 | 发送问题，AI 提取核心论点 | "这本书的核心观点和主要论点是什么？" |
| 章节导航 | 发送问题，AI 介绍章节结构 | "请介绍一下这本书的章节结构，帮助我了解全书的框架" |
| 关键概念 | 发送问题，AI 提取术语概念 | "这本书有哪些关键概念和重要术语？" |
| 作者背景 | 发送问题，AI 介绍作者信息 | "请介绍一下这本书的作者及其背景" |
| 探索这本书 | AI 主动发问，引导用户选择阅读方式 | 特殊处理（见下文） |

### "探索这本书"特殊处理

点击"探索这本书"后，发送的提示词为：

```
用户刚刚开始阅读这本书，请主动发起对话，询问用户想以什么方式阅读：
- 如果想快速了解，可以推荐检视阅读（概览、章节导航）
- 如果想深入理解，可以推荐分析阅读（重点章节、核心观点）
- 如果想建立关联，可以推荐主题阅读（与已读书籍对比）

用自然友好的语气，不要过于结构化。
```

### 触发时机

- 用户切换到一本新书（或首次打开书籍）
- 该书籍没有任何对话记录
- 显示在消息列表的空状态区域

### 消失时机

- 用户点击任意引导按钮后，按钮区域消失
- 用户手动输入并发送第一条消息后，按钮区域消失
- 对话记录存在后，不再显示引导按钮

### 接口修改

`MessageCallbacks` 接口需要扩展：

```typescript
export interface MessageCallbacks {
  // 现有回调...
  onGenerateOutline?: () => void;

  // 新增：通用引导按钮点击回调
  onGuidanceClick?: (type: GuidanceType) => void;
}

export type GuidanceType =
  | 'overview'        // 这本书讲了什么
  | 'core-views'      // 核心观点
  | 'chapter-nav'     // 章节导航
  | 'key-concepts'    // 关键概念
  | 'author-info'     // 作者背景
  | 'explore';        // 探索这本书
```

## 验收标准

1. 切换到新书时，显示 6 个引导按钮
2. 点击前 5 个按钮，发送对应问题，AI 正常回复
3. 点击"探索这本书"，AI 主动发问引导用户
4. 点击任意按钮或发送消息后，引导按钮消失
5. 切换到有对话记录的书籍，不显示引导按钮
6. 样式与现有 UI 风格一致
