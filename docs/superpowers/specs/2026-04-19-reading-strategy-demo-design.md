# 阅读策略示范设计文档

## 设计概述

### 核心问题

当前产品的用户心智模型停留在"翻页模式"——把书当文章读，逐字逐句推进。大多数用户知道"应该带着问题读书"、"应该找命题"，但不知道**怎么具体操作**。

这是**能力障碍**：用户有抽象的阅读理念，但没有可执行的操作策略。

### 设计目标

通过"阅读策略示范"功能，把抽象的"主动阅读"转化为用户可观察、可模仿、可练习的具体操作，逐步培养用户的阅读能力。

### 核心理念

**观察 → 参与 → 自主**的学习路径（基于 Bandura 的社会学习理论）：

- Level 1（新手）：用户旁观 AI 示范
- Level 2（进阶）：用户填空练习
- Level 3（熟练）：用户自主阅读，AI 提供对比反馈

## 用户心智模型分析

### 能力障碍的三个断层

| 断层 | 问题表现 | 示范如何解决 |
|------|----------|-------------|
| **目标模糊化** | "我要读这本书"是愿望，不是目标 | 通用模板的五步，把"读书"转化为具体目标序列 |
| **策略缺失** | 用户知道应该主动阅读，但不知道怎么操作 | AI 示范展示可执行的动作，用户看到具体操作 |
| **反馈缺失** | 用户读完一章，不知道自己理解到什么程度 | 用户自己做后可以对比 AI 示范，获得差距反馈 |

### 心理学原理支撑

| 设计元素 | 心理学原理 | 应用 |
|---------|----------|------|
| 通用模板固定 | 认知架构理论 | 用户形成稳定的策略心理模型 |
| 动态内容贴合 | 情境学习理论 | 示范内容有意义，不是抽象演示 |
| 模式切换 | 自主调节理论 | 用户控制支架程度，增强自我效能感 |
| 渐进难度 | 最近发展区（Vygotsky）| 始终在用户能力边缘提供支持 |
| 观察学习 | Bandura 社会学习理论 | 通过观察高手行为习得策略 |

## 功能设计：混合示范模式

### 通用模板（固定框架）

Adler 的阅读策略可提炼为**五个固定步骤**，对所有书籍适用：

```
Step 1: 识别关键词
  问题：这本书的关键概念是什么？
  操作：划词 → 标记为"关键词"

Step 2: 找核心命题
  问题：作者在主张什么？
  操作：找到句子 → 判断是否是命题 → 提取

Step 3: 分析论证结构
  问题：命题怎么被证明的？
  操作：找前提 → 找推论 → 找结论

Step 4: 质疑命题
  问题：我同意吗？为什么？
  操作：列举异议 → 提供证据 → 判断立场

Step 5: 关联其他知识
  问题：这和我已知的知识有什么关系？
  操作：跨书搜索 → 概念对比 → 整合观点
```

### 动态内容（AI 生成）

针对具体书籍章节，AI 生成贴合内容的示范：

```
针对《思考，快与慢》第1章的示范：

Step 1 动态内容：
  → AI 标注："系统1"、"系统2"、"认知偏差"是关键词
  → AI 解释：这些概念在书中反复出现，是核心概念

Step 2 动态内容：
  → AI 找到命题："人类决策有两个系统"
  → AI 解释：这段有定义+论证，是全书核心命题

Step 3 动态内容：
  → AI 分析论证：
     前提：系统1 是快速直觉
     推论：快速直觉容易出错
     结论：需要系统2 校验

Step 4 动态内容：
  → AI 提出质疑："系统1 一定出错吗？"
  → AI 说明：书中后文讨论系统1 的优势

Step 5 动态内容：
  → AI 关联："《助推》讨论了如何利用系统1"
  → AI 说明：跨书主题阅读
```

### 模式切换设计

用户可以在三种模式间切换：

| 模式 | 显示内容 | 适用用户 |
|------|----------|---------|
| **看示范** | 通用模板 + AI 示范内容 | 新手（Level 1）|
| **自己做** | 只显示通用模板 | 进阶/熟练（Level 2-3）|
| **关闭** | 隐藏任何提示 | 熟练用户 |

    { 
      id: 'propositions', 
      name: '找核心命题',

    { 
      id: 'arguments',

    {

### AI 示范生成

```
调用时机：
  - 用户首次打开章节，选择"看示范"
  - 用户主动点击"请求示范"

输入：
  - 章节 Markdown 内容
  - 书的元信息（书名、目录、主题）
  - 用户已读书籍列表（用于 Step 5 关联）

输出：
  - Step 1: 关键词列表 + 判断依据
  - Step 2: 呸题 + 位置 + 判断依据
  - Step 3: 论证结构 + 逻辑位置
  - Step 4: 质疑 + 质疑依据
  - Step 5: 关联书籍 + 关联理由

LLM 调用：
  - 使用现有 Agent 的 analytical 模式
  - 增加 structured_output 确保格式一致
```

### 用户操作记录

```
记录用户在每个步骤的操作：
  - 用户找到的关键词
  - 用户选择的命题
  - 用户分析的论证结构
  - 用户提出的质疑

用于：
  - 与 AI 示范对比
  - 生成差距反馈
  - 追踪用户能力成长
```

## 用户测试方案

### 测试目标

验证"混合示范模式"是否真的解决了**能力障碍**。

### 测试指标

| 指标 | 测量方式 | 目标 |
|------|----------|------|
| 策略习得 | 用户能否在没有示范时自主完成五步 | 从 Level 1 升级到 Level 3 |
| 阅读质量 | 用户找到的命题 vs AI 示范命题的匹配度 | ≥ 70% |
| 用户满意度 | 用户认为"示范帮到了我"的比例 | ≥ 80% |
| 使用频率 | 用户主动请求示范的比例 | 初期高，后期降低（说明能力迁移）|

### 测试流程

```
1. 招募测试用户：
   - 新用户（未读过书）
   - 中级用户（读过 1-3 本书）
   - 熟练用户（读过 > 5 本书）

2. 测试任务：
   - 打开新书的第一章
   - 选择示范难度
   - 完成阅读

3. 测试后访谈：
   - 你觉得示范有帮助吗？
   - 你学会了什么策略？
   - 你下次会怎么做？
```

## 参考心理学文献

1. **目标设定理论**：Locke & Latham (2002) - 模糊目标不触发具体行动
2. **自我效能感**：Bandura (1997) - 无策略的能力信念脆弱
3. **元认知理论**：Flavell (1979) - 没有反馈的学习无效
4. **最近发展区**：Vygotsky (1978) - 在能力边缘提供支架
5. **社会学习理论**：Bandura (1977) - 观察学习是最有效的策略习得方式
6. **情境学习理论**：Lave & Wenger (1991) - 学习需要具体情境
