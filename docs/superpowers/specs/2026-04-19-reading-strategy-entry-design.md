# 阅读策略入口设计文档

## 核心需求

用户知道"应该带着问题读书"、"应该找命题"，但不知道**怎么具体操作**。

解决方案：提供**策略入口**，用户点击后触发 AI 苏格拉底式引导。

---

## 操作入口设计

### 工具栏入口

```
阅读工具栏：
[划词] [高亮] [标注] [策略▽]

策略下拉菜单：
├─ 识别关键词
├─ 找命题  
├─ 分析论证
├─ 质疑命题
├─ 关联知识
└─ ─────────────
   难度设置
```

### 入口特点

- 常驻可见，不干扰阅读
- 用户主动点击 → 触发 AI 对话
- 苏格拉底式引导：AI 分析后提问，用户选择确认

---

## AI 响应方式：苏格拉底式引导

### 对话流程：分析后提问 + 选择确认

```
用户点击策略 → AI 分析章节 → 提供 3-5 个候选 → 用户选择 → AI 分析该候选 → 用户确认/修改
```

### 示例对话（找命题）

```
AI：我分析了这一章，以下是可能有命题的段落：

├─ 段落 1："系统1 是快速的..."（可能定义核心概念）
├─ 段落 3："人类决策有两个系统..."（可能是全书核心命题）
└─ 段落 7："直觉会产生偏差..."（可能是论证推论）

你选择哪个段落？

用户：段落 3

AI：这段的命题分析：

命题："人类决策有两个系统"
判断依据：这段有定义（系统1、系统2）+ 论证（为什么需要两个系统）

你觉得这个命题判断对吗？或者你想补充？

用户：是的，这就是核心命题

AI：好的，已记录。这个命题可以作为后续论证分析的起点。
```

## 各策略的 AI 响应

| 策略 | AI 响应流程 |
|------|-----------|
| **识别关键词** | AI 分析 → 提供候选关键词 → 用户选择 → AI 解释原因 |
| **找命题** | AI 分析 → 提供候选段落 → 用户选择 → AI 分析命题 → 用户确认 |
| **分析论证** | 用户选命题 → AI 找论证结构 → 用户确认前提/推论/结论 |
| **质疑命题** | 用户输入异议 → AI 追问原因 → 用户解释 → AI 整合评注 |
| **关联知识** | AI 搜索其他书籍 → 提供关联章节 → 用户选择 → AI 对比观点 |

## 与现有 Agent 整合

复用现有 S1/S2 能力：

| 策略 | 复用能力 |
|------|---------|
| 找命题 | S2 命题提取 |
| 分析论证 | S2 论证分析 |
| 关联知识 | S2 跨书搜索 |

**新增**：苏格拉底引导模式（候选→选择→确认）

```

```
