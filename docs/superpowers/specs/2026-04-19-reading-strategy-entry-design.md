# 阅读策略入口设计文档

## 核心需求

用户知道"应该带着问题读书"、"应该找命题"，但不知道**怎么具体操作**。

解决方案：提供**策略入口**，用户主动学习，无 AI 参与。

---

## 操作入口设计

### 工具栏入口

```
阅读工具栏：
[划词] [高亮] [标注] [策略▽]

策略下拉菜单：
├─ 识别关键词：划词 → 判断是否核心概念
├─ 找命题：找句子 → 判断是否作者主张  
├─ 分析论证：前提 → 推论 → 结论
├─ 质疑命题：异议 → 证据 → 立场
├─ 关联知识：跨书对比 → 整合观点
└─ ─────────────
   难度设置
```

### 入口特点

- 常驻可见，不干扰阅读
- 用户主动点击，自主决定何时学习
- 无 AI 参与，纯静态策略说明

---

## 五步策略模板

| 步骤 | 操作说明 |
|------|---------|
| **1. 识别关键词** | 划词 → 判断是否反复出现、是否是核心概念 → 标记 |
| **2. 找命题** | 找句子 → 判断是否是作者的主张（有定义+论证）→ 提取 |
| **3. 分析论证** | 找前提 → 找推论 → 找结论 → 画出论证链 |
| **4. 质疑命题** | 判断立场 → 列举异议 → 提供证据 → 写评注 |
| **5. 关联知识** | 搜索其他书籍 → 对比观点 → 整合到笔记 |

---

## 触发逻辑（可选）

### 被动提示

用户标注时，工具栏旁显示微提示：

```
用户标注了关键词 → 提示："还可以尝试：找命题"
用户标注了命题 → 提示："还可以尝试：分析论证"
```

**特点**：
- 非侵入式，可折叠
- 只是引导用户探索下一步策略
- 不强制，用户可忽略

---

## 交互流程

### 主动学习流程

```
用户阅读 → 点击"策略" → 选择具体步骤 → 阅读操作说明 → 回到阅读 → 应用策略
```

### 被动提示流程

```
用户标注 → 提示"下一步策略" → 点击查看 → 回到阅读 → 继续标注
```
