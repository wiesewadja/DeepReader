# 阅读策略示范设计文档

## 核心问题

用户知道"应该带着问题读书"、"应该找命题"，但不知道**怎么具体操作**。

这是**能力障碍**：有抽象理念，没有可执行策略。

---

## 设计方案：嵌入式示范

### 核心理念

示范不作为独立功能，而是**嵌入阅读操作中**：
- 用户划词 → 标注菜单显示示范 → 点击展开 → 完成标注
- 单流操作，不需要切换"阅读↔学习"模式

---

## 操作入口

### 1. 工具栏常驻入口

```
阅读工具栏：
[划词] [高亮] [标注] [帮助▽]

帮助下拉菜单：
├─ 看阅读策略示范
├─ 学习：识别关键词
├─ 学习：找命题
├─ 学习：分析论证
├─ ─────────────
├─ 难度设置
└─ 关闭示范提示
```

**特点**：常驻可见，随时可访问，不干扰阅读。

---

### 2. 困难触发入口（智能提示）

AI 判断用户可能需要帮助时，温和提示：

**触发条件**：

| 条件 | 判断逻辑 | 提示内容 |
|------|----------|---------|
| 划词未标注 | 用户划词但没选标注类型 | "不知道怎么标注？[看示范]" |
| 标注类型单一 | 用户只标注关键词，没标注命题 | "这段可能有命题 [看示范]" |
| 停留时间长 | 用户在某段停留 > 30秒 | "需要帮助吗？[看示范]" |
| 反复回看 | 用户回看同一段 > 3次 | "这段的理解要点 [看示范]" |

**提示样式**：气泡或侧边栏微提示，非侵入式。

---

## 触发逻辑

### 智能触发流程

```
用户操作 → AI 监测 → 判断是否需要帮助 → 显示提示

触发时机：
1. 用户划词 → 弹出标注菜单 → 菜单中包含"看示范"选项
2. 用户标注但类型单一 → 侧边栏微提示"还有其他标注类型"
3. 用户停留困惑 → 气泡提示"需要帮助吗"
```

### 主动触发流程

```
用户点击"帮助" → 下拉菜单 → 选择具体步骤 → 显示示范

步骤选项：
- 识别关键词：划词 → 判断是否核心概念
- 找命题：找句子 → 判断是否作者主张
- 分析论证：找前提→推论→结论
```

## 展示方式：原文内嵌气泡

```
原文：
"系统1 是快速的、自动的..."

示范叠加：
"系统1" [虚线高亮] ← 用户点击
    ↓
气泡展开：
┌─────────────────────┐
│ 📘 AI 示范           │
│                     │
│ 标注类型：关键词     │
│ 原因：全书核心概念   │
│                     │
│ [关闭]              │
└─────────────────────┘
```

**特点**：
- 示范嵌入原文，不切换面板
- 渐进揭示：用户可选择展开
- 最小侵入，不干扰阅读流

---

## 交互流程：单流操作

```
用户操作流：

1. 划词 → 弹出标注菜单
2. 菜单中显示：
   "标注为关键词（示范：AI 标注了'系统1'）"
3. 点击"示范" → 展开气泡
4. 查看示范 → 决定是否采纳
5. 完成标注 → 继续阅读

核心：示范整合到标注操作，不额外切换状态
```

## 阅读策略模板（AI 示范内容）

五步固定框架：

| 步骤 | 问题 | 操作 |
|------|------|------|
| 1. 识别关键词 | 这本书的关键概念？ | 划词 → 标记为"关键词" |
| 2. 找核心命题 | 作者在主张什么？ | 找句子 → 判断是否命题 |
| 3. 分析论证 | 命题怎么被证明？ | 前提 → 推论 → 结论 |
| 4. 质疑命题 | 我同意吗？为什么？ | 异议 → 证据 → 立场 |
| 5. 关联知识 | 和已知知识的关系？ | 跨书搜索 → 对比 |
