## 一、项目概述

**DeepReader** 是一个 Obsidian 插件，通过 FastAPI 后端为 PDF/EPUB 文档提供智能索引和问答服务。

### 技术架构
- **前端**: TypeScript (Obsidian Plugin API)
- **后端**: Python 3.10+ (FastAPI)
- **通信**: REST API @ `http://localhost:6088`
- **向量数据库**: ChromaDB
- **LLM**: DeepSeek / OpenAI

| 树状章节结构 | - | ✅ | 使用 PageIndex 解析 |
| 阅读进度追踪 | - | ✅ | 记录已读页码 |
| 文本格式化 | - | ✅ | 规范化段落 |

#### 索引流程（6 步骤）
1. **验证文件** (10%) - 检查文件存在和大小
2. **检查 LLM 配置** (20%) - 验证 API Key
3. **初始化 PageIndex** (30%) - 配置加载
4. **创建 LLM 客户端** (40%) - UnifiedLLM 实例
5. **解析文档结构** (50%) - PageIndex 树状解析
6. **存储到 ChromaDB** (80%) - 向量化和持久化

#### 关键配置参数
| 参数 | 说明 |
|------|------|
| `max_pages_per_node` | 每节点最大页数 |
| `max_tokens_per_node` | 每节点最大 token 数 |
| `toc_check_pages` | 目录检测页数 |
| `if_add_node_summary` | 是否生成章节摘要 |
| `visual_detect_sample_pages` | PDF 视觉类型检测采样 |
| `visual_text_threshold` | 文本密度阈值 (500) |
| `visual_density_threshold` | 图片密度阈值 (0.3) |

## 三、数据流架构

### 3.1 索引流程
```
PDF/EPUB 文件
    ↓
PageIndex 库（树状结构解析）
    ↓
LLM 生成章节摘要（可选）
    ↓
文本格式化
    ↓
ChromaDB 向量存储 + 元数据 JSON
```

### 3.2 对话流程
```
用户输入
    ↓
路由模式判断（auto/fast/section/slow）
    ↓
Agent ReAct 循环
    ├── 工具选择与执行
    ├── 结果评估
    └── 响应生成
    ↓
流式/非流式输出
```

### 3.3 存储结构
```
backend/deeppdf-api/data/
├── indexes/           # 索引元数据 JSON
├── chroma/           # ChromaDB 向量数据
├── configs/           # 用户配置
├── chats/            # 会话历史
└── uploads/          # 上传的文件
```

## 七、已知限制和注意事项

1. **启动要求**: 后端必须使用 `--loop asyncio` 标志，不能使用 uvloop
2. **端口配置**: 默认 6088，修改需同步前后端
3. **Pydantic 配置**: `.env` 需与 `Settings` 类匹配
4. **ChromaDB**: 每个索引创建一个 collection
