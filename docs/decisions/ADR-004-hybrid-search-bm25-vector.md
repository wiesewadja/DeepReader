# ADR-004: BM25 + 向量混合搜索

## 状态
Accepted

## 日期
2026-03（项目创始）

## 背景

AI Agent 需要在已索引的书籍中搜索内容。搜索质量直接决定 AI 回答的准确性——搜不到的内容，AI 无法引用。

## 决策

采用 BM25（关键词）+ 向量（语义）混合搜索，用 RRF（Reciprocal Rank Fusion）融合排序。

## 替代方案

### 纯向量搜索
- 优点：语义理解强，"类似概念"能匹配
- 缺点：专有名词、精确术语召回差；需要 embedding 模型，增加配置门槛
- 放弃原因：书籍中有大量专有名词和精确术语，纯向量会漏掉

### 纯 BM25
- 优点：零配置，速度快，精确匹配强
- 缺点：语义理解弱，"如何管理团队"搜不到"领导力"相关内容
- 放弃原因：用户提问是自然语言，关键词不一定出现在原文中

### 向量 + Cross-encoder 重排
- 优点：精度最高
- 缺点：需要额外的 reranker 模型，增加延迟和成本
- 放弃原因：作为可选增强（v2 搜索管线），不作为基础方案

## 后果
- BM25 是零配置的底线能力，向量搜索按需开启
- 向量搜索需要 embedding 模型（用户需配置），增加初次使用门槛
- 两个搜索系统的结果融合需要调参（RRF k 值）
