# DeepPDF 前端交互优化设计文档

**日期**: 2025-01-18
**版本**: 1.0

---

## 1. 概述

本文档定义了 DeepPDF 前端的交互优化方案，旨在提供更流畅的用户体验和更清晰的状态反馈。

### 1.1 核心目标

- **对话式搜索**：将侧边栏重构为类似 ChatGPT 的聊天界面，支持追问和上下文理解
- **索引进度可视化**：实时显示索引创建的各阶段进度
- **流程整合**：将索引管理与对话界面分离但紧密联动

### 1.2 痛点分析

| 痛点 | 描述 |
|------|------|
| 进度不可见 | 选择文件后只能干等，不知道处理到哪一步 |
| 流程分散 | 需要在多个模态框之间切换，流程不连贯 |

## 2. 整体布局架构

### 2.1 布局结构

```
┌─────────────────────────────────────┬─────────────────────┐
│  DeepPDF 侧边栏（对话界面）           │  抽屉面板（索引管理） │
│                                     │  (点击按钮滑出)       │
│  ┌───────────────────────────────┐  │                     │
│  │ 💬 消息列表                   │  │  ┌─────────────────┐ │
│  │                               │  │  │ 📊 索引管理     │ │
│  │ ┌─────────────────────────┐   │  │  ├─────────────────┤ │
│  │ │ 用户消息                │   │  │  │ [+ 新建索引]    │ │
│  │ └─────────────────────────┘   │  │  │                 │ │
│  │ ┌─────────────────────────┐   │  │  │ 索引列表:       │ │
│  │ │ AI 回复                 │   │  │  │ ┌─────────────┐ │ │
│  │ │ + 引用来源              │   │  │  │ │论文.pdf      │ │ │
│  │ └─────────────────────────┘   │  │  │ │⏳ 45% 解析中 │ │ │
│  └───────────────────────────────┘  │  │ └─────────────┘ │ │
│  ┌───────────────────────────────┐  │  └─────────────────┘ │
│  │ 输入问题...              [📤]│  │                     │
│  └───────────────────────────────┘  │                     │
│                                     │                     │
│  [索引: 论文.pdf ▼]    [📊 管理索引] │                     │
└─────────────────────────────────────┴─────────────────────┘
```

### 2.2 设计原则

1. **分离关注点**：对话界面专注问答，索引管理独立在抽屉面板
2. **可访问性**：使用 Obsidian CSS 变量适配不同主题
3. **实时反馈**：所有操作都有明确的状态指示


**组件说明**：

## 5. 索引进度可视化

### 5.1 后端进度步骤

| 步骤 | 进度范围 | 说明 |
|------|----------|------|
| `start` | 0% | 任务开始 |
| `init_pageindex` | 5-30% | 初始化 PageIndex 配置 |
| `create_llm_client` | 30-40% | 创建 LLM 客户端 |
| `parse_pdf` | 40-70% | 解析 PDF 结构 |
| `store_chromadb` | 70-90% | 存储到向量数据库 |
| `save_metadata` | 90-95% | 保存元数据 |
| `completed` | 100% | 完成 |

### 5.2 前端步骤配置

```typescript
const STEP_CONFIG = {
  "start": { label: "任务开始", icon: "🚀", minPercent: 0, maxPercent: 5 },
  "init_pageindex": { label: "初始化索引配置", icon: "⚙️", minPercent: 5, maxPercent: 30 },
  "create_llm_client": { label: "连接 LLM 服务", icon: "🔌", minPercent: 30, maxPercent: 40 },
  "parse_pdf": { label: "解析 PDF", icon: "📄", minPercent: 40, maxPercent: 70 },
  "store_chromadb": { label: "存储向量数据", icon: "🗄️", minPercent: 70, maxPercent: 90 },
  "save_metadata": { label: "保存元数据", icon: "💾", minPercent: 90, maxPercent: 95 },
  "completed": { label: "完成", icon: "✅", minPercent: 95, maxPercent: 100 }
};
```

### 5.3 前端轮询策略

- 抽屉面板每 2 秒轮询一次进行中的任务
- 任务完成后停止轮询
- 使用 `GET /api/tasks/{task_id}/progress` 获取进度

## 9. 用户旅程

```
1. 打开侧边栏 → 看到对话界面（空状态）
2. 点击"管理索引" → 抽屉滑出
3. 点击"新建索引" → 选择 PDF 文件
4. 返回抽屉 → 看到实时进度条
5. 索引完成 → 通知 + 自动切换到新索引
6. 关闭抽屉 → 返回对话界面
7. 输入问题 → 获取 AI 回复 + 引用来源
8. 追问 → 上下文对话
```

## 10. 实现优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 抽屉面板基础框架 | 滑入/滑出动画 |
| P0 | 索引任务进度展示 | 轮询 + 进度条 |
| P0 | 对话界面基础结构 | 消息列表 + 输入框 |
| P1 | 消息 Markdown 渲染 | 代码高亮 |
| P1 | 引用来源展示 | 可跳转 PDF |
| P2 | 会话历史管理 | 新建/切换对话 |
| P2 | 错误处理优化 | 各类错误提示 |
