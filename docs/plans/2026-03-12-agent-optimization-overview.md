## 二、优化方向

根据现有实现，优化方向调整为：

### Phase 1: 会话持久化增强 ✅ (已完成)

**现状**: 前端已实现完整的会话持久化（`chatCache`）

**可选增强**:
- 添加 `last_consolidated` 标记（为记忆整合做准备）
- 支持会话导出/导入

**结论**: 此 Phase 已基本完成，无需大改动

---

### Phase 2: 双层记忆系统增强

**现状**: 已有记忆工具 (`add_memory`, `search_memory`)

**优化点**:
1. **MEMORY.md 结构化**: 规范化长期记忆格式
2. **HISTORY.md 时间线**: 添加查询历史日志
3. **智能整合机制**: 当 Token 超过阈值时自动触发整合
4. **`last_consolidated` 标记**: 追踪已整合的消息边界

**详细计划**: [2026-03-12-phase2-dual-layer-memory.md](./2026-03-12-phase2-dual-layer-memory.md)

---

### Phase 3: 子 Agent 系统

**现状**: 已有占位实现 (`create-sub-agent.ts`)

**优化点**:
1. **完整实现**: 使子 Agent 能真正执行任务
2. **并行检索**: 支持同时搜索多个章节
3. **结果通知**: 子 Agent 完成后通知主 Agent
4. **资源隔离**: 限制子 Agent 的工具权限

**详细计划**: [2026-03-12-phase3-subagent-system.md](./2026-03-12-phase3-subagent-system.md)

---

### Phase 4: 分层系统提示

**现状**: 已有 `buildSystemPrompt()` 函数

**优化点**:
1. **4 层架构**: Identity → Bootstrap → Memory → Tools
2. **运行时注入**: 将动态信息注入用户消息（而非系统提示）
3. **LLM 缓存优化**: 保持系统提示稳定
4. **Bootstrap 文件**: 支持自定义提示文件

**详细计划**: [2026-03-12-phase4-layered-system-prompt.md](./2026-03-12-phase4-layered-system-prompt.md)
