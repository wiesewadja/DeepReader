# 读书笔记生成

## 触发场景

- "帮我写读书笔记"
- "生成这本书的阅读笔记"
- "整理这个章节的内容"
- "总结这本书的要点"

## 笔记类型

### 1. 章节笔记
- **用途**: 单章节的详细笔记
- **路径**: `读书笔记/{书名}/{章节名}.md`
- **结构**:
  ```markdown
  # {章节名}

  ## 核心观点
  {章节的核心论点}

  ## 关键内容
  - 要点1
  - 要点2

  ## 个人思考
  {自己的理解和感悟}

  ---
  > 来源: {Link}
  ```

### 2. 全书笔记
- **用途**: 整本书的综合性笔记
- **路径**: `读书笔记/{书名}/全书总结.md`
- **结构**:
  ```markdown
  # 《{书名}》读书笔记

  ## 书籍信息
  - 书名: {书名}
  - 核心主题: {一句话概括}

  ## 核心观点
  1. 观点1
  2. 观点2

  ## 章节要点
  ### 第一章: {章节名}
  {要点}

  ## 我的收获
  {个人收获和启发}

  ## 行动计划
  - [ ] 行动1
  - [ ] 行动2
  ```

### 3. 主题笔记
- **用途**: 围绕某个主题整理跨章节内容
- **路径**: `读书笔记/{书名}/主题-{主题名}.md`
- **结构**:
  ```markdown
  # {主题名}

  ## 主题概述
  {这个主题在书中的定位}

  ## 相关内容
  ### {章节1}
  {相关内容}

  ### {章节2}
  {相关内容}

  ## 总结
  {整合观点}

  ---
  > 来源: {Link1}, {Link2}
  ```

## 执行流程

1. **确定范围**: 单章节、全书还是特定主题
2. **获取内容**: 使用 get_toc 了解结构，get_chapter 获取内容
3. **提取要点**: 识别核心观点、关键论据
4. **整合笔记**: 按模板结构组织内容
5. **添加思考**: 加入个人理解和感悟
6. **保存笔记**: 使用 write_note 保存

## 质量标准

- 结构清晰，层次分明
- 核心观点突出，不遗漏重点
- 必须包含 Link 引用
- 个人思考部分要有深度，不是简单复述
- 全书笔记要体现整体框架和逻辑脉络

## 复杂任务处理

如果任务涉及多个章节（超过3个），使用 create_sub_agent 拆分：
- 每个子 Agent 处理 1-2 个章节
- 主 Agent 汇总整理
- 子 Agent 串行执行
