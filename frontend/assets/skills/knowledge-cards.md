# 知识卡片生成

## 触发场景

- "帮我生成知识卡片"
- "提取这本书的核心概念"
- "收集书中的金句"
- "把这段内容做成卡片"

## 卡片类型

### 1. 概念卡
- **用途**: 解释核心概念
- **路径**: `知识卡/概念/{概念名}.md`
- **结构**:
  ```markdown
  # {概念名}

  ## 定义
  {清晰定义}

  ## 要点
  - 要点1
  - 要点2

  ## 示例
  {具体例子}

  ---
  > 来源: {Link}
  ```

### 2. 金句卡
- **用途**: 收集精彩语句
- **路径**: `知识卡/金句/{章节}-{序号}.md`
- **结构**:
  ```markdown
  > {原句}

  ## 解读
  {个人理解}

  ---
  > 来源: {Link}
  ```

### 3. 方法卡
- **用途**: 记录可操作的方法
- **路径**: `知识卡/方法/{方法名}.md`
- **结构**:
  ```markdown
  # {方法名}

  ## 步骤
  1. 步骤1
  2. 步骤2

  ## 注意事项
  - 注意点1

  ---
  > 来源: {Link}
  ```

## 执行流程

1. **理解需求**: 确认要生成哪种类型的卡片
2. **搜索内容**: 使用 search_doc 找到相关段落
3. **深度阅读**: 使用 get_chapter 获取完整上下文
4. **生成卡片**: 按模板格式整理内容
5. **保存笔记**: 使用 write_note 保存到 Obsidian

## 质量标准

- 每张卡片只包含一个核心概念/金句/方法
- 必须包含 Link 引用来源
- 内容精炼，避免大段摘抄
- 解读部分要有个人理解，不是简单复述
