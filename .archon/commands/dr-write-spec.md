# 生成 SPEC.md

用户回答: $ARGUMENTS

## 任务

1. 调用 agent-skills:spec 技能，基于以下信息生成 SPEC.md：
   - 前一步探索中用户的原始想法
   - 用户对关键问题的回答
   - 代码库现状

2. SPEC 格式要求（参考项目现有 SPEC.md 风格）：

```markdown
# [特性名称]

> 版本：YYYY.MM.DD | 状态：DRAFT

## 目标
一段话说明要做什么、为什么做。

## 架构
- 涉及的模块/文件
- 新增 vs 修改的文件列表
- 关键接口设计

## API / 集成规范
- 新增的接口或数据结构
- 与现有模块的交互方式

## 成功标准
- [ ] 验收条件 1
- [ ] 验收条件 2
- ...

## 不做（Out of Scope）
明确列出本期不做的内容。
```

3. 将生成的 SPEC 写入项目根目录 `SPEC.md`

4. 输出 SPEC 全文供审批

## 规则
- SPEC 用中文撰写
- 成功标准必须是可验证的复选框
- 代码标识符和文件路径用英文
- 参考 .project-rules/ 下的架构和开发规范
